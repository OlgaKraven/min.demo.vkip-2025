## Предметная область

**Модуль 1** — работа с обращениями пользователей: классификация заявок, документирование, ответы клиентам, технологические карты.

**Модуль 2** — развёртывание MySQL, создание БД, пользователей и таблиц, настройка прав доступа, системное администрирование.
